How to use this page

Find a Place helps your group explore a convenient meeting point based on everyone's starting location.

  1. Enter a postcode or location for each person.
  2. Use “+ add person” to add someone, or “×” to remove them.
  3. Choose your travel settings, then select “Search for a place to meet”.
  4. Click a route to view its journey steps.
  5. Use “Change recommendation” button to view another suggested place.
